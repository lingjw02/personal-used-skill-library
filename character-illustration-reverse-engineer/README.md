# Character Illustration Reverse Engineer

> **AI Skill**: Deconstruct reference illustrations into structured visual specifications and craft high-fidelity generation prompts that maintain character identity while elevating composition, anatomy, lighting, and art quality.

---

## 📌 Overview

**Character Illustration Reverse Engineer** takes an existing character image (anime, fantasy, game art, OC, fan art, or character sheet) and extracts its load-bearing visual DNA. Instead of producing vague caption prompts like *"girl with long red hair in armor"*, this skill reverse-engineers the design into a **rigorous design specification** and a **16-section prompt** that ensures the character remains immediately recognizable across any new pose, camera angle, or lighting setup.

### Core Philosophy
> **"The reference is a design source, not a prompt."**
> A casual caption throws away the exact silhouette, costume layering, color balance, and signature motifs that make a character unique. The goal of this skill is that any new generation feels like **"the same character in a new premium artwork"**, never *"a different character vaguely inspired by the reference."*

| **Prompt Architecture** | Unstructured sentence fragments competing for model attention | 16-section standardized prompt placing load-bearing identity anchors in high-attention token windows |

## 🎯 4-Tier Design Hierarchy

When generating a character in a new scene, this hierarchy controls what must stay fixed versus what is free to adapt:

- 🔒 **Tier 1 — MUST Preserve**: Face structure, eye color/shape, hair color/style/bangs, signature motifs, overall body silhouette.
- 🎨 **Tier 2 — SHOULD Preserve**: Major costume layers, primary/secondary color palette, distinctive textures, material weight.
- ✂️ **Tier 3 — CAN Reinterpret**: Minor fabric folds, subtle embroidery, tertiary seam lines, tiny accessories.
- 🌐 **Tier 4 — CAN Change Freely**: Background, environment, camera perspective, dynamic lighting, atmospheric particles, wind direction.

> **Rule of thumb**: When prompt token budgets are tight, always cut from Tier 4 upwards—never sacrifice Tier 1 identity anchors.

## 📝 The 16-Section Prompt Structure

Prompts generated by this skill follow a standardized visual hierarchy, placing identity anchors first (where models apply the highest weighting):

```text
[1 CHARACTER IDENTITY]  Age, gender presentation, build, and Critical Identity List.
[2 HAIR]                Color, length, silhouette, bangs, ornaments, flyaway locks.
[3 FACE]                Face contour, iris color & specular details, eyebrows, features.
[4 BODY]                Proportions, anatomy stylization level, posture baseline.
[5 COSTUME]             Layer-by-layer breakdown: innerwear, outerwear, trim, textures.
[6 DISTINCTIVE MOTIFS]  Signature emblems, asymmetry, specialized gear, exact placement.
[7 POSE]                Weight distribution, limb placement, dynamic balance.
[8 EXPRESSION]          Micro-expression, mouth shape, gaze direction.
[9 CAMERA]              Shot type (wide/medium/close), elevation angle, focal length.
[10 COMPOSITION]        Focal point hierarchy, rule-of-thirds, negative space.
[11 ENVIRONMENT]        Contextual setting subordinated to character readability.
[12 LIGHTING]           Key light, fill light, directional rim light, bounce color.
[13 MATERIALS]          Specular behavior: matte fabric, metallic sheen, leather gloss.
[14 ATMOSPHERE]         Volumetric fog, embers, wind-driven petals, or dust motes.
[15 RENDERING STYLE]    Linework weight, shading technique, textural finish.
[16 QUALITY CONTROL]    Positive anatomical statements + structured negative prompt.
```

## 💡 How to Use

### In Agent Environments (Antigravity, Claude Code, Cursor)
Whenever an agent with this skill is active:
- Upload an image or describe a character.
- Prompt: *"Reverse-engineer this character into a Midjourney prompt"*, *"Make a polished illustration of my OC in a battle stance"*, *"Write a prompt to keep this character consistent across new scenes"*.

### Target Model Compatibility
- **Midjourney v6 / v6.1**: Excellent adherence to the 16-section structure; convert quality statements into style parameters (`--s`, `--c`).
- **Stable Diffusion (SDXL / Pony / Illustrious)**: Directly supports positive and negative prompt blocks.
- **Flux.1 / DALL-E 3**: Excels with the descriptive, natural-language phrasing of the 16-section skeleton.
