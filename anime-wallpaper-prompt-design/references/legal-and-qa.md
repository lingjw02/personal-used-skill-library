# 法律、伦理与发布风险 + 最终验收清单

## 原创优先

对于原创角色、立绘和商业壁纸，最安全也最有资产价值的方向始终是：原创角色 + 原创服装 + 原创徽记 + 自己可证明的设计过程。

使用知名动漫角色名称、复制辨识度极高的制服/徽章/武器/logo，与"生成一名动漫风格角色"不是同一风险级别。生成平台允许输入某个角色名称，不等于自动授予商业发行、商品化或广告使用的知识产权许可。各司法辖区的版权、商标、人格权和衍生作品规则不同，商业化前需要针对实际发行地做法律审查（此处不构成法律意见）。

## 关于"某位在世插画师风格"

不建议把 `in the exact style of [某位在世插画师]` 当作高质量 Prompt 的必要组成部分。抛开具体司法辖区对"风格本身"保护边界的争议不谈，从创作质量角度，替换成更专业可控、也更原创的具体视觉属性描述通常效果更好：
```
thin tapered ink linework,
flat cel shadows,
muted pastel palette,
elongated silhouettes,
soft atmospheric backgrounds,
high-contrast rim lighting
```
这比单纯写艺术家名字更容易建立自己稳定可复现的视觉语言。

## 真人参考

应比动漫角色参考更谨慎处理。真实人物的肖像权、隐私权、商业人格权和 deepfake 相关规则因司法辖区而异；使用他人真实相貌作为参考存在被识别、被滥用或引发权利纠纷的风险。商业项目应优先使用已取得许可的真人参考，或完全原创的虚拟角色，避免未经授权复制可识别的真实个人形象。

## AI 生成内容的版权归属现状（截至撰写时，需持续关注变化）

AI 生成并不等于自动获得完整版权。纯 AI 生成内容本身通常不受版权保护；包含足够人类原创表达、选择、编排或创意修改的作品，其相应人类创作部分则可能获得保护，且需逐案判断。单独依靠 Prompt，通常不足以证明对输出的表达元素有足够的作者控制。这一领域的规则仍在演变中，具体结论应以当地最新法律/官方指引为准，不应把本文当作定论。

对希望角色视觉资产有更充分可证明人类创作投入的创作者，建议保留创作过程记录：
```
人物原始文字设定 → 自己绘制/设计的角色草图 → 配色方案 → 服装结构设计
→ Prompt/Seed/Workflow 版本 → AI 初始生成 → 人工选择与组合
→ 人工 redraw/paint-over → 手动调整服饰/五官/背景/排版 → 最终成稿
```
这不能自动保证任何司法辖区的版权结论，但比"输入一次 Prompt 后原样发布"显著增加可记录的人类创作过程。

## 模型/服务许可证

发布前应核对所用模型和服务本身的许可条款（例如本地部署模型的模型卡许可条件，或云端服务关于生成图像商业使用权、所有权主张的条款）。不同平台在这一点上差异很大，且条款会随时间更新，使用前应查阅该服务当前的官方条款而非依赖旧信息。

## 最终验收 QA 清单

| QA 项 | 合格标准 |
|---|---|
| 构图 | 人物位置适配图标/时钟安全区 |
| 完整性 | 要求全身时头、手、脚均完整 |
| 面部 | 双眼方向、瞳孔、睫毛、脸型无明显异常 |
| 手部 | 手指数量、握持逻辑、遮挡关系合理 |
| 服装 | 左右结构、扣件、饰品连续无错位 |
| 人物一致性 | 发型、眼睛、永久饰品与角色设定一致 |
| 光源 | 主光、轮廓光、阴影方向不明显冲突 |
| 色盘 | 主色/辅色/点缀色清晰，无意外污染 |
| 背景 | 不抢主体；安全区足够安静干净 |
| 文本 | 没有无意义乱码文字 |
| IP | 无意外品牌、现有作品 logo、签名 |
| 技术 | 最终比例和尺寸准确 |
| 放大 | 无 halo、过锐、塑料皮肤、线稿断裂 |
| 发布 | 已检查模型/服务许可证和目标用途是否合规 |

## 长期资产建议

比起维护"100 条漂亮 Prompt"，更值得长期维护的是三套资产：**角色规范（Character Bible）**、**壁纸构图规范（Wallpaper Layout）**、**模型适配器（Model Adapter）**。Prompt 只是这三者在某个模型上的一次编译结果，方便后续切换模型或批量生产时复用。
